## Установка и запуск

1.  **Клонируйте репозиторий:**

    ```bash
    git clone https://github.com/HarsatMKad/Web_Lab6.git
    cd Web_Lab6
    ```

2.  **Установите docker, если он не установлен.**

3.  **При необходимости настройте `.env` в папке каждого микросервиса:**

    ```
    PORT=               # Порт, на котором будет запущен сервер
    DB_URL=             # URL для подключения к вашей MongoDB.
    JWT_SECRET=         # Секретный ключ для JWT.
    и т.д.
    ```

4.  **Установите контейнеры и запустите сервер:**

    ```bash
    docker-compose up --build
    ```
